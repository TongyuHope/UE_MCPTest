# BiomePCG 样条绘制工具：首版使用说明

## 当前交付状态

已添加源码实现，包括 Runtime Actor/样条组件和独立的编辑器绘制模式。
编辑器绘制方式现支持“长按拖动”和新增的“逐点点击”，默认保留长按拖动。
按约定没有运行 C++ 编译、编辑器加载或交互验证；以下是编译后待验收的使用流程。
没有创建、修改或执行用户 PCG 图，也没有在当前工程中生成蓝图或写入关卡资产。

## 1. 编译与打开工具

### 旧版蓝图水印处理

旧 PCGSenc 插件迁入的 ProjectionDebug 会自动给 `/Game/PCG` 下的蓝图和 PCG 图添加覆盖层，因此此前创建的 `BP_BiomeSplinePainter` 也可能保存了这种节点。
目前已移除插入行为，旧节点的兼容类型不再显示文字或背景；打开、保存资产时只移除这两种旧水印节点。

编译并重启编辑器后，重新打开 `/Game/PCG/BP_PCG/BP_BiomeSplinePainter` 并保存，无需删除或重建蓝图，也不必重画关卡中的样条。
尚未在当前正在运行的编辑器里执行清理或写入该 uasset；新行为需要编译后的插件生效。
其他受影响 Blueprint/PCG Graph 可同样重新打开、保存。
旧类型及历史重定向保留用于资产兼容，不会按字符串匹配删除用户自己的注释。

### 打开绘制模式

1. 编译 `UE_MCPTestEditor / Win64 / Development`，重新打开工程。此次包含新的反射类型，建议关闭编辑器后完整编译。
2. 在顶栏选择 `TA Tools → 绘制样条植被`。
3. 也可以在编辑模式下拉菜单选择 `Biome 样条绘制`。
4. 左侧应出现工具设置面板。进入 PIE 时绘制模式自动退出。

## 2. 放置与绘制

在面板 `Drawing → 绘制方式` 中选择模式。放置 Actor 的首次点击在两种模式下都不创建样条。

### 长按拖动（默认）

1. 保持“目标 Actor”为空，在有碰撞的 Landscape 或 StaticMesh 表面单击左键。
2. 该次单击只放置 Actor，不生成样条。
3. 再次按住左键拖动，黄色折线显示尚未提交的控制点预览。
4. 松开左键，创建一条独立的 `UBiomePaintedSplineComponent`，平滑开关决定提交后的曲线类型。
5. 再次按住左键会创建另一条新样条，归属同一个 Actor，不与上一条连接。

“放置蓝图类”留空时，首次放置会创建或复用：

```text
/Game/PCG/BP_PCG/BP_BiomeSplinePainter
父类：ABiomeSplinePainterActor
```

工具创建的蓝图和关卡会标记为待保存，请自行保存。
默认路径已有不兼容资产时会拒绝覆盖，可以在面板指定另一个继承自 `ABiomeSplinePainterActor` 的蓝图类。

若要继续编辑已有 Actor：先选中该 Actor 再进入工具，或通过面板“目标 Actor”选择实例。
也可以选中实例后点击“使用选中的绘制 Actor”。
点击“放置新的 Actor”会清空当前目标，下一次单击放置另一个 Actor。

### 逐点点击

1. 选择“逐点点击”，放置 Actor 或选择已有绘制 Actor。
2. 单击地表添加第一点，再单击其他位置添加第二点、第三点等。
3. 鼠标移动只显示绿色候选线段；黄色点和线段代表已确认的控制点。拖动与松开均不自动加点或提交。
4. 至少确认两个不同的点，且线长达到最短有效长度后，按 Enter 或点击“完成当前线 / 绘制下一条”。
5. 工具提交一条完整样条并保持开启；下一次单击开始另一条独立线，仍属于当前 Actor。
6. Backspace、Ctrl+Z 或“回退最后一点”移除当前线最后一个确认点；回退全部点后可开始新线。
7. Esc 或“取消当前逐点线”丢弃当前未提交线，不影响已保存样条。

逐点模式不会自动补上鼠标悬停点，最后一个端点必须由点击确认。
控制点最小间距及最大连续跨越距离仅用于长按模式；逐点模式允许用户手动指定较长的线段。
重复点击距离上一点不超过 1 cm 的位置不会添加重合点。
两种模式都沿用“平滑曲线”开关；需要精确折线时关闭该开关。

点击工具面板或切换视角不会取消逐点线。切换绘制方式、切换目标、地图或进入 PIE 时，当前未提交线会被取消。
“完成绘制”在逐点线有效时先提交再退出；仅有一个点或长度不足时保留当前线并提示，可继续补点或先取消再退出。

## 3. 接入自己的 PCG 图

可以在面板“用户 PCG 图”指定资产，再点击“将图和自动刷新设置应用到目标”。
也可以退出工具，在 Actor 的 `PCGComponent` 中直接指定 Graph。

- 面板中的图只在新建 Actor 或点击应用按钮时写入目标。
- 点击应用时，空 Graph 代表清除目标 Graph；不会自动创建 PCG 图。
- 未指定 Graph 时照样可以绘制、保存、删除样条。
- Actor 的 PCG 组件默认使用 `GenerateOnDemand`。提交后自动刷新默认开启，也提供手动刷新。
- 若用户将组件改成 `GenerateAtRuntime`，工具不抢占运行时生成调度；首版编辑器预览请使用默认 OnDemand 设置。

PCG 读取接口：

| 项目 | 值 |
| --- | --- |
| 输入来源 | 当前 Actor / Self |
| 组件类型 | USplineComponent 的派生类 `UBiomePaintedSplineComponent` |
| Component Tag | `BiomePaintedSpline` |
| 多线输出 | 需要读取全部目标 Spline，不只读取第一个 |
| 点生成规则 | 由用户图中的 Spline Sampler 等节点实现 |
| 每条线标识 | 组件上保存 `StrokeId` GUID 和可编辑 `StrokeLabel` |

`GetPaintedSplines` 也暴露为普通蓝图可调用的纯函数。
工具不约束植被间距、植物种类、Mesh 列表或图参数名称。
控制点间距只影响绘制形状，不等同于 PCG 图里的植被间距。

## 4. 编辑操作

| 操作 | 行为 |
| --- | --- |
| Esc，笔画中 | 取消当前临时笔画，不留下组件 |
| Esc，空闲时 | 退出工具 |
| 完成绘制 | 逐点模式先提交有效当前线再退出；其他情况下保留已提交内容并退出 |
| Ctrl+Z / Ctrl+Y，空闲时 | 使用编辑器事务撤销 / 重做 |
| Ctrl+Z / Ctrl+Y，长按模式笔画中 | 取消当前临时笔画 |
| Enter / 完成当前线，逐点模式 | 提交已点击确认的点，然后准备绘制下一条 |
| Backspace / Ctrl+Z，逐点线中 | 回退最后一个已确认点 |
| Ctrl+Y，逐点线中 | 提示先完成或取消当前线，不调用编辑器重做 |
| 点击样条列表中的一条线 | 蓝色高亮该条已保存样条 |
| 删除选中样条 | 删除当前目标上高亮的线，可撤销 |
| Alt+鼠标 / 右键 | 保留常规视口导航 |

长按拖动期间只绘制临时预览，松开后才写入持久化组件并请求 PCG 刷新。
逐点模式则仅在显式完成当前线时写入持久化组件并请求刷新，逐次点选不创建持久化样条组件。
刷新请求会短暂合并；当前组件正在生成或清理时等待其结束，不为每次鼠标移动启动生成。
刷新现采用分阶段处理：等待编辑事务和既有 PCG 任务结束，清理当前绘制 Actor 的旧输出，完成后重新获取样条数据并生成。
PCG 分区组件也只处理该 Actor 对应的局部组件，不调用全场景的“清除所有 PCG 组件”。
生成期间发生的新编辑会排队进行下一轮更新。

### 重开项目后旧植被残留的修复

本机日志曾对 `BP_BiomeSplinePainter` 报出 `Null generated resource encountered`，且错误出现在撤销变换之后。
这说明 PCG 的生成资源列表中存在空记录；仅再次调用生成接口不能可靠回收失去管理记录的旧输出。
该日志并不能单独确定空记录最初产生于保存、加载还是撤销流程。

现在会在组件空闲时过滤当前 Actor 及其注册分区组件的无效资源记录。
加载后的首次刷新、撤销后的刷新、手动刷新或检测到空记录时，使用引擎的单组件清理/回收接口处理旧输出及失去管理关系的 PCG 生成对象，然后再生成。
普通后续编辑也先完成组件清理，再重新生成，不直接叠加生成结果。
保存、编辑事务或 PIE 进行期间不启动该刷新链。
加载本身不主动清空已保存植被，等第一次编辑或手动刷新时再处理。

用户编译并重启编辑器后，可先对已有绘制 Actor 使用一次“刷新目标 PCG”，然后保存关卡。
再重开项目、移动一处样条控制点，确认旧位置实例消失、新位置实例出现；再检查撤销和重做。
无需为了验证本修复清除其他 Actor 的 PCG 结果。
该修复尚未运行编译或场景复现验证。

如果 PCG 组件被设为 Preview / Load As Preview，生成结果是否保存仍遵循 UE 的该模式规则，工具不强制改写此设置。

结束绘制模式后，可使用普通 Spline 控制点编辑已保存的样条。
组件属性编辑、控制点编辑、Actor 移动完成及撤销会通知 PCG 更新。
用户自己的蓝图 Construction Script 不应删除或覆盖手绘实例组件。

## 5. 地表与中断处理

- 默认使用 Visibility 通道，地表必须具有对应的碰撞响应。
- 自动忽略目标 Actor 自身，并可忽略带 PCG 生成标记的 Actor/组件，避免在植被顶部继续绘制。
- 鼠标无命中时不加点；长按模式跨越距离超过设置值时结束当前有效笔画，松开左键后才能开始下一条。
- 短点击或不足最小长度的笔画会被丢弃。
- 长按模式视口失去焦点会取消临时笔画；逐点模式保留已确认点，便于使用面板按钮。切换地图或开始 PIE 两种模式均清理临时线。
- 平滑曲线只保证控制点在命中位置；控制点之间可能穿过地面，最终植被贴地应由用户 PCG 图处理。

默认控制点最小间距 100 cm，最短笔画 10 cm，最大连续跨越距离 2000 cm。
最大跨越距离的实际下限为两倍控制点最小间距。

## 7. 用户验收顺序

1. 无 Graph 放置 Actor；确认第一次点击没有样条。
2. 连画三次，确认一个 Actor 中有三条独立组件。
3. 验证短笔画、Esc 取消、跨空洞和视口导航。
4. 验证整笔撤销 / 重做、列表选中、删除及恢复。
5. 保存关卡和自动创建的蓝图，重开关卡检查样条。
6. 复制 Actor、编译其蓝图后检查样条实例是否保留。
7. 指定用户图，确认 Get Spline Data 读取全部三条线，逐条按距离生成植被。
8. 结束绘制后修改原生控制点，检查 PCG 刷新是否符合预期。
9. 切到逐点模式，点击三个点；移动鼠标和松开左键不应添加额外点或提交。
10. 点击面板“完成当前线”，确认保存一条恰好三个点的样条，没有把鼠标悬停位置加入末尾。
11. 继续点选下一条线并按 Enter，确认得到第二条独立线；测试 Backspace、Ctrl+Z、取消及只有一个点时的完成提示。
12. 逐点线未提交时切换视角或点击面板，确认点位保留；切换绘制方式后确认仅当前临时线取消。
13. 保存并关闭项目后重开，移动一个已保存控制点，确认旧植被被替换；验证撤销/重做后无叠加残留。
14. 场景放置两个绘制 Actor，只修改其中一个，确认另一个 Actor 的生成结果未被清除。
15. 连续快速编辑时确认清理与生成顺序正确，最终植被对应最后一次样条状态；关闭自动刷新后仅手动刷新才替换输出。
