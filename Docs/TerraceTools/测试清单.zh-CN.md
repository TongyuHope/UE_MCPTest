## 2. 建议编译方式

1. 在 UE 中保存当前工作，确认 TerraceTools 已启用，然后关闭编辑器。
2. 必要时右键 `UE_MCPTest.uproject` 重新生成工程文件，使 IDE 显示新 Editor 模块。
3. 在 IDE 选择 `Development Editor / Win64`，构建 `UE_MCPTest`。
4. 编译完成后重新打开项目，确认无插件模块缺失或加载失败提示。

也可在 PowerShell 手动执行（由用户执行）：

```powershell
& 'E:\UE_5.8\Engine\Build\BatchFiles\Build.bat' UE_MCPTestEditor Win64 Development '-Project=D:\UEProjectReal\UE_MCPTest\UE_MCPTest.uproject' -WaitMutex
```

本次新增 UCLASS 和模块，建议完整重启，不通过 Live Coding 验收新类型是否可用。若编译失败，保留第一条错误及其附近上下文供修复，后续错误可能由第一条引起。

## 3. 自动化测试

在 UE 的 Automation 面板搜索 `TerraceTools`，运行以下三组。若未显示，检查 Editor 模块是否加载及是否为带开发测试的 Editor 构建。

| 测试 | 预期 |
| --- | --- |
| `TerraceTools.Geometry.PolygonValidity` | 简单轮廓、两种绕序通过；蝴蝶结、共线、重顶点、相邻回折、非相邻触碰、重复闭合点、空输入和非有限坐标被拒绝 |
| `TerraceTools.Geometry.ConcaveAndDistance` | L 形两臂内部被保留、缺口外部被排除；边/顶点命中、边界距离正确；平移至大世界坐标后面积和包含结果不变 |
| `TerraceTools.Input.SettingsAndBudget` | 默认值合法；零行距、负埂高、NaN 和超过 512 顶点被拒绝 |

预期为三组全部通过。数学测试不覆盖 Actor 生命周期、序列化、视口注册或任何地形后端。

## 4. 编辑器人工验收

在独立测试关卡进行，首批无需 Landscape。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| M0-01 | 放置 Terrace Group，点击新增田块 | 产生一个 TerracePlot，并加入组；不出现任何地形变更 |
| M0-02 | 以默认设置校验 Plot | 通过；默认 64 个采样点，矩形 20 m × 12 m |
| M0-03 | 设 Actor Z=1000 cm、Elevation Offset=200 cm | 标高辅助线位于世界 Z=1200 cm，校验结果显示该标高 |
| M0-04 | 选中 Plot，再选中 Group | Plot 显示自身辅助线；Group 显示已加载成员辅助线 |
| M0-05 | 编辑成 L 形闭合凹多边形 | 校验通过，无凸多边形限制；形状应至少保持 0.1 cm 的边界间距 |
| M0-06 | 编辑成自交蝴蝶结 | 校验失败且显示原因；显示青线不代表合法 |
| M0-07 | 关闭 Closed Loop，或制造重复控制点 | 校验失败，不返回有效快照 |
| M0-08 | Actor Pitch=10°，或设负缩放 | 校验失败，提示保持水平和正向缩放 |
| M0-09 | 旋转 Actor Yaw、设置正向非均匀 XY 缩放 | 轮廓随变换更新，控制点角点仍保留；预算允许时校验通过 |
| M0-10 | 在默认大矩形上设置 Sample Spacing=1 cm | 超过 512 预算而失败；恢复 100 cm 后通过 |
| M0-11 | 抬高若干控制点，点击控制点归平 | 控制点局部 Z 全为 0，Elevation Offset 不变；撤销可还原 |
| M0-12 | 点击新增田块，然后 Undo / Redo | Actor 与组成员引用一起撤销/恢复；反复操作无残留重复项 |
| M0-13 | 普通复制一个 Plot | 新 Plot ID 与原田块不同；不会自动加入原组 |
| M0-14 | 保存、关闭并重新打开关卡 | 原 Plot ID、边界、参数和成员引用保持 |
| M0-15 | 重复把同一 Plot 加入 Plots 数组 | 整组校验失败；删除重复项后恢复 |
| M0-16 | 删除成员 Plot 或卸载其区域，再校验组 | 明确失败，不静默忽略成员，不删除其他内容 |
| M0-17 | 开始 PIE | 没有 Tick 生成行为，不新增地形/作物；PIE 副本 Plot ID 保持；返回编辑器后数据不变 |

组内重叠、共享边界、跨组成员冲突、Landscape 加载状态和碰撞不是 M0 校验项。M0 通过不代表这些后续功能已完成。
