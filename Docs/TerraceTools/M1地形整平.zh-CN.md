# M1 地形整平小样：使用与验收

日期：2026-10-20。源码版本：0.2.0。**用户已反馈 M1 当前检验通过，未提供逐项测试记录；编译与验收由用户执行。** 本文保留使用方式、限制和预期验收项；后续参考文章研究见 [方案调整](参考文章与方案调整.zh-CN.md)。

0.3.0 补充：更新地形会记录供 M2 校验的已应用输入，并清理本组旧结构；移除 Patch 贡献或删除其输出也清理本组结构。升级后先更新一次地形，再按 [M2 文档](M2田埂与护坡.zh-CN.md) 生成田埂/土坡。

0.3.1 补充：为解决边界插值导致田埂支撑高度不匹配，自动在边界外增加平坦支撑余量 P，再开始外围过渡；P = Landscape XY 网格对角线 + √2×Terrain Raster Spacing + 1 cm。升级后必须重新更新地形；生成占地扩大，以下参数表按新行为说明。源码修复未编译/运行 UE 验证。

## 1. 本轮变化

- Plot 与 Group 参数统一进入靠前的“梯田工具 / Terrace Tools · 参数”，操作分类紧邻其上。
- 插件声明 LandscapePatch 依赖；新加编辑器专用输出 Actor、覆盖遮罩栅格化和地形更新工具。
- 组新增“更新地形”和“移除地形贡献”按钮。
- 每组创建一个专用 Patch 编辑层，每块田一个 Texture Patch；整组更新前先检查边界、田块间距、地形范围、可表示标高和预算。
- 新一代输出配置就绪后才替换上一代；更新不叠加雕刻值。输出纹理作为可序列化子对象保存，不依赖临时 Render Target。
- 输出归属按组引用与 Actor Owner 检查；复制组不继承输出引用；删除组清理其拥有的输出，删除输出清除所属组引用。这些生命周期与 Undo 行为仍需实际验收。

## 2. 首版范围

先在**非 World Partition 普通测试关卡**使用一个组、1～5 块田，使用无 Visibility 洞、无旋转的 Landscape。代码目前明确拒绝 World Partition 地形更新。

不支持共享田边或重叠过渡带，尚不处理跨组影响冲突、其他上层地形编辑对结果的覆盖、自动道路沟渠或田埂。支持 Plot Yaw 和正向缩放；Landscape 只允许平移与正向缩放，Pitch/Yaw/Roll 均接近 0。

地形顶点分辨率仍由 Landscape 决定。遮罩分辨率更高不会增加地形顶点，近边界会受双线性插值和高度量化影响，不能用此阶段生成锐利窄埂或垂直墙。

## 3. 用户操作

1. 保存工作，关闭 UE，完整编译并重启。新增编辑器 UCLASS 与 LandscapePatch 依赖，不建议用 Live Coding 验收。
2. 新建普通关卡，创建一块有足够边界余量的 Landscape，雕出缓坡作为输入。
3. 放置 Terrace Group，指定 `Target Landscape` 为主 Landscape Actor，而不是 Streaming Proxy。
4. 新增一个 Plot，将边界完全放在地形内部。遮罩还会在边界外扩展 `P + Transition Width + Terrain Raster Spacing`，需给地形边缘留出余量。
5. 修改 Plot Actor Z / Elevation Offset，使青线位于期望的台地高度。
6. 回到 Group，点击“更新地形”。失败时看详情状态和 Output Log；输入预检失败不会替换原有结果。
7. 等 Landscape 可见形状更新后，再用角色检查脚底碰撞。成功提示只表示更新已提交，不表示重组、碰撞、导航或 Nanite 派生数据均已完成。
8. 改标高、边界或位置后再次点击更新；不会在拖动时实时写地形。
9. 点击“移除地形贡献”，等待更新，检查恢复到当前下层编辑层结果。移除指禁用本组 Patch，不删除基础地形和其他层。
10. 保存测试关卡与被修改的地形相关包，关闭重开，检查结果与引用。

本轮未接 PCG，因此没有“等待地形完成后自动散布”的隐藏行为。完成条件与下游调度在接 PCG 时另行实现；不能以固定延时作为最终同步方案。

## 4. 参数和保守约束

| 参数/限制 | 行为 |
| --- | --- |
| Plot / Transition Width | 默认 150 cm，在自动平坦支撑余量 P 之外以 smoothstep 平滑衰减；田内及支撑带遮罩为 1 |
| Group / Terrain Raster Spacing | 默认 100 cm，最小 10 cm；控制遮罩间距，不改变 Landscape 分辨率 |
| Plot / Sample Spacing | 轮廓离散间距，仍需满足最多 512 点 |
| 田块间距 | 大于两块 Transition Width 之和 + 2×(P + Terrain Raster Spacing)；接触、包含和相交均拒绝 |
| 默认第二块田 | 新增时沿 Y 错开 1500 cm；默认矩形间仅 300 cm，不满足地形过渡余量，需手动移远或减小过渡宽度 |
| 每组田块数 | 1～16；首轮人工验收建议不超过 5 |
| 单块遮罩 | 最多 513×513 |
| 整组遮罩 | 最多 1,048,576 像素，并限制轮廓计算预算 |
| 地形覆盖 | 整个遮罩矩形（包含一圈透明留边）必须在有效已加载组件范围内 |
| 标高 | 不能超过目标 Landscape 高度编码可表示的范围；不是任意世界 Z 都能被该 Landscape 表示 |

第一轮可使用分离田块验证正确性。收紧共享边界和邻接逻辑后，再实现连续梯田，不通过 Patch 顺序覆盖来掩盖冲突。

## 5. 数据和撤回

生成的 `TerraceTerrainOutput` 是编辑器专用 Actor，与组位于同一 Level。内部 Patch 和非 sRGB、无 Mip、非流送的 RGBA8 遮罩保存于关卡包；遮罩红通道为 0，Alpha 表示覆盖，通过 `WorldUnits + PatchZ` 把该零值解释为田块世界标高，避免用 8 bit 通道编码绝对高度。

更新先创建禁用的新输出、配置并等待遮罩纹理资源就绪，再禁用旧输出、启用新输出并替换组引用，最后删除旧输出。基础 Heightmap 不被直接覆写。

“移除贡献”保留禁用输出和工具层供后续使用；正常更新复用同一层。失败发生在新建层之后时可能留下空层，避免自动删除引擎层造成误删；可在确认未被引用后手动删除空层。

地形更新、移除、组/输出删除纳入编辑器事务，但 **Undo/Redo、异步地形重组与保存重开的最终效果尚需人工验证**。移除后恢复的是“当前下层组合”，不会强行恢复到其他地编修改之前的旧快照。

换 Target Landscape 前先移除旧贡献；原 Landscape 的空层可能保留。不要手动移动/缩放输出 Actor 或改其 Patch 设置，修改应从 Plot 与 Group 发起。旧输出未加载时会拒绝更新，避免产生重复结果。

删除 Plot 后，先修复组内失效引用，再更新整组，才会移除该田块的旧贡献。仅删除 Plot 不立即改变地形。

## 6. 新增自动化测试（用户执行）

在 Automation 面板搜索 `TerraceTools`。原三组几何测试保留，新增：

| 测试 | 预期 |
| --- | --- |
| `TerraceTools.Terrain.PlotSeparation` | 分离边界距离正确；接触、相交、包含为零；过渡带冲突拒绝，失败不返回旧遮罩 |
| `TerraceTools.Terrain.MaskAndBudget` | 采样尺寸正确；田内 Alpha=255，外围透明，过渡中点约 128；红通道为零；超预算和无效间距被拒绝 |

这两组只测试数学输入和遮罩，不能证明 Patch 绑定、GPU 混合、Undo 或碰撞正确。

## 7. 本轮人工验收表

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M1-01 | 选中原 M0 Plot | 参数与操作分类均有“梯田工具”前缀，均排在详情靠前位置；原参数值保留 |
| M1-02 | 不指定 Landscape 点击更新 | 给出目标提示，不产生输出和地形修改 |
| M1-03 | 缓坡中间放一块田，更新 | 创建专用 Patch 层和一个输出 Actor；田内形成目标标高台地，边界外有过渡 |
| M1-04 | 不改参数连续更新三次 | 高度不累积，活跃输出 Actor 不增加，工具层不重复创建 |
| M1-05 | 改标高再更新 | 台地随标高变化，保持原地形 XY 对齐 |
| M1-06 | 平移 Plot 再更新 | 原位置恢复下层地形，新位置形成田块；预览未点击更新前不改地形 |
| M1-07 | 修改为凹多边形 | 凹缺口不被当整矩形填平；外围留边无方形高度补丁 |
| M1-08 | 移除贡献 | 下层地形恢复，其他编辑层及手摆内容保留；重复移除无额外影响 |
| M1-09 | 移除后再次更新 | 恢复台地，复用原工具层 |
| M1-10 | 更新、移除分别 Undo / Redo | Actor 引用、Patch 启用状态与地形结果一致；等待重组后无旧结果叠加 |
| M1-11 | 保存重开 | 遮罩、Patch 绑定、层 GUID 与台地保持，再次更新有效 |
| M1-12 | 加第二块田并放得足够远，设不同标高 | 两块台地各自平整，无顺序覆盖；移除时一起恢复 |
| M1-13 | 两田重叠、相触或过渡太近，再更新 | 明确拒绝，旧有效结果保留 |
| M1-14 | 遮罩越出 Landscape、标高超出编码范围 | 拒绝提交，旧有效结果保留 |
| M1-15 | 隐藏/锁定工具层或改其高度 Alpha，再更新 | 提示先修复层状态，不自动覆盖艺术家设置 |
| M1-16 | 换 Target Landscape，旧贡献仍启用 | 提示先移除；移除后切换可创建新目标的工具层 |
| M1-17 | 删除输出 Actor 后再次更新 | 组输出引用清除，可重建；Undo 删除需恢复引用与地形 |
| M1-18 | 删除 Group，然后 Undo / Redo | 本组输出一并清理/恢复，其他组和手摆对象不受影响 |
| M1-19 | 角色进入台地、行走并跨过缓过渡 | 视觉面与碰撞一致，无旧山坡隐形碰撞；暂不要求窄田埂可行走 |
| M1-20 | WP 地图或旋转 Landscape 请求更新 | 明确拒绝，不产生半成品输出 |
| M1-21 | 修改 Raster Spacing 或轮廓导致超预算 | 明确拒绝且不替换旧结果，不出现长时间无提示大分配 |

若出现“青线正确但田面标高或 XY 偏移不对”，优先提供 Landscape 的 Transform、Plot 世界 Z/偏移、Raster Spacing、目标层状态和 Output Log 第一条异常。M1 尚未做打包验收，不将编辑器可见结果等同于 Shipping 已通过。
